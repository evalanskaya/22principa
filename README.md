# Ева Ланская — мобильный лендинг

Статический сайт для GitHub Pages. Включает тест из 5 вопросов, 3 варианта результата, страницу предложения продукта за 990 ₽ и документы. Оплата не подключена; кнопка показывает заглушку. Нет сбора email или ответов теста.

## Публикация

1. Создайте публичный репозиторий `eva-lanskaya` в GitHub.
2. Загрузите в корень репозитория файлы `index.html`, `style.css`, `script.js`, `offer.html`, `privacy.html`, `terms.html`, `contacts.html`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Откройте `https://nichatski.github.io/eva-lanskaya/` после публикации.

## Обязательно до отправки на согласование

- Вставить настоящее ФИО владельца/продавца, страну, правовой/налоговый статус и требуемые местным законодательством реквизиты.
- Вставить реальную почту/Telegram поддержки и публичный Instagram проекта.
- Утвердить формат готового продукта, способ/срок выдачи и порядок возвратов.
- Юридически проверить оферту и политику под страну продавца, место аудитории и фактические обработчики данных.
- Предоставить ссылки на существующие публичные отзывы реальных клиентов или согласовать с менеджером их отсутствие у нового продукта.
- При подключении оплат дополнить документы данными о платежном провайдере и передаваемой ему информации.
- Убедиться, что банк/Platega одобряет соответствующий статус физлица и заявленный продукт.

Код проверки `Agetalp` размещён в футере главной страницы и в документах. Никакие настоящие платежи не принимаются.

## API

GitHub Pages — статический хостинг, не храните здесь API-ключи Platega. Подключайте оплату через отдельный backend, который создаёт платёж и проверяет его статус, и только после подтверждения выдаёт доступ к товару.
