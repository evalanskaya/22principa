# Ева Ланская — мобильный лендинг с тестом

## Что работает
- Главная страница, интерактивный тест из пяти вопросов, три варианта персонального результата
- Предложение цифрового минипродукта, отображение цены из config.js
- Кликабельная кнопка покупки с уведомлением об отключенной оплате
- Публичные страницы политики конфиденциальности, соглашения, контактов и код Agetalp
- Вёрстка для мобильных экранов (на больших экранах сайт показан в узкой колонке)

## Перед публикацией / отправкой в банк
1. Заменить ВСЕ значения-заглушки в `config.js`, включая цену, реальное юридическое имя продавца, контакты, формат и доставку.
2. Согласовать и дополнить `privacy.html`, `terms.html` под применимую юрисдикцию, оплату, возвраты, обработку данных. Это рабочие черновики, не готовые юридические документы.
3. Добавить ссылку на Instagram и публичные отзывы реальных покупателей, если есть. Не фабриковать отзывы.
4. Проверить реальный состав и готовность продукта, стоимость и способ исполнения обязательств.
5. Проверить доступность сайта со стороннего устройства/без входа.
6. Не размещать приватные API-ключи в `config.js` или любом другом файле GitHub Pages. Подключение Platega потребует серверной части.

## Публикация через GitHub Pages
1. Создать публичный репозиторий `eva-lanskaya`.
2. Загрузить все файлы из этой папки в корень репозитория.
3. Settings → Pages → Build and deployment: Deploy from a branch → Branch `main`, Folder `/ (root)` → Save.
4. Адрес после публикации: `https://nichatski.github.io/eva-lanskaya/` (если аккаунт и имя репозитория совпадают).

## Важно
Ответы теста пока НЕ сохраняются и не отправляются: обработка полностью локальная в браузере. Реальной платежной интеграции нет.
